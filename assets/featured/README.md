# Featured covers

Sixteen original vector covers, each 1200 × 630 pixels. Every SVG is the editable source and its matching PNG is a browser-rendered copy. `contact-sheet.png` is a review sheet. No PDFs, product screenshots or stock images are included.

| github | The work, in one place. |
| feeling-good | Feeling Good |
| tonality | Tonality |
| early-interruptions | Early Interruptions |
| quick-deflections | Quick Deflections |
| discovery | Discovery |
| listening | Listening to Your Guest |

Regenerate from the repository root with `nice -n 19 node assets/featured/generate.mjs`. Install Playwright in your environment, or set `PLAYWRIGHT_DIR` to an existing installation directory. Set `CHROME_PATH` if Chrome is outside `/usr/bin/google-chrome`. It checks text bounds and renders with one local browser. The document covers are intended for thumbnail use only where the original PDF remains intact.
