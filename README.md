# Steven Ammer

I spent 15 years in consumer phone sales as an agent, supervisor and trainer, and I still work the phones. Now I build AI workflows people can check. I write the specs, I try to break what comes back, and I decide what ships.

I'm learning in public, so some of this is rough on purpose.

A thought-capture app that never loses your original and never makes work for you. [Try the interactive walkthrough](https://stevenammer.github.io/effort-demo/), or read the [case study](https://github.com/stevenammer/effort-demo/blob/main/docs/CASE_STUDY.md) on how I break my own specs.

## How I work

- I don't write most of the code now. Agents do. My job is to say what done looks like, test it hard, and decide what's safe to ship.
- I would rather publish the rough version and say what's wrong with it than polish it until nobody can check it.

## Not here

My employer's work, anyone else's data, and anything I haven't checked.
